# Privacy Policy

RadioMaroc does not collect, sell, share, or profile personal data.

The app stores only local preferences on the device: selected language, display mode, favorites, and recent stations. These values are not uploaded anywhere.

Network connections are made only to:
1. the selected radio stream host, to play audio;
2. a broadcaster website, when attempting to display its station artwork.

There is no analytics service, advertising network, crash-reporting SDK, account system, cloud sync, or remote configuration service in the application.

The source code and build workflow are public so these claims can be independently inspected.
