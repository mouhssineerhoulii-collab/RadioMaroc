# Radio Maroc — راديو المغرب

تطبيق أندرويد مجاني ومفتوح المصدر للاستماع إلى الإذاعات المغربية، موجّه خصوصاً للمغاربة داخل الوطن وخارجه.

## المبادئ
- مجاني بالكامل.
- بدون إعلانات.
- بدون متتبعات إعلانية.
- تشغيل الإذاعات في الخلفية.
- واجهة مغربية واضحة.
- دعم العربية والفرنسية والإنجليزية.
